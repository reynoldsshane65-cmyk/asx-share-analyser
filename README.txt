ASX Share Analyser Phase 7 — Custom Score Filters

Built on Phase 6 VPA + Sector Accuracy app.

1. Back up your current app.py and SQLite prediction database.
2. Replace GitHub app.py with the app.py in this ZIP.
3. Keep your other files unchanged.
4. Run a scanner first. Open Early-Mover Tracker or VPA Scanner.

7. Filtered table, exports and share selection reflect the filtered results.
